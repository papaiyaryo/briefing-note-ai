## 準備

1. テストDBが起動していることを確認する（`docker ps` で `briefing-note-u1-test-postgres-1` が healthy）。止まっていれば `docker compose -f compose.test.yml up -d --wait`。
2. リポジトリ直下で `node scripts/local-workspace-preview.mjs` を実行する。表示された `http://127.0.0.1:3000` を Chrome で開き、dummy本人でログインする（パスワードはスクリプト内のローカル専用値）。
3. このpreviewは **5分で自動停止し、専用schemaごと削除** される。1回で全部終わらなくてよい。終わったら次のrunで続ける。終了時は端末に `stop` と入力し、出力の `dedicatedPreviewStopConfirmed: true` / `dedicatedSchemaDropped: true` を確認する。
4. データは架空の企業名・メモだけを使う（実在の説明会メモ・OCR内容は使わない）。同じブラウザで2タブ（A・B）を開く。
