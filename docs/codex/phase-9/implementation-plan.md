# Phase 9 実装計画: 企業比較・面接前復習

## Phase 目的

Phase 9 では、MVP で作成した企業別メモを横断的に比較し、志望度整理、懸念点の確認、ES / 面接前復習に使える導線を設計・実装する。

## 対象 Issue

1. Issue #44: 企業比較用データ構造を設計する
2. Issue #45: 企業比較テーブルと志望度メモ機能を実装する
3. Issue #46: 面接前復習モードと ES 接続ポイント生成を実装する

## 実装順序

1. Issue #44 で比較用データ構造と情報分離方針を確定する。
2. Issue #45 で比較 UI と志望度メモを、Issue #44 の構造に基づいて実装する。
3. Issue #46 で面接前復習モードを、比較用構造と ES / 面接対策観点に基づいて実装する。

## 依存関係

- Phase 4 の `CompanyMemoStructured` が存在すること。
- Phase 8 の Web 補足情報は、紙メモ由来情報とは別枠で扱うこと。
- MVP の単一メモ作成・編集・ダウンロードが完了していること。

## 共有設計方針

- `CompanyMemoStructured` は変更せず、比較専用の派生構造を追加・参照する。
- 紙メモ由来の事実、個人の印象、HR / 社員が強調した点、後で聞く質問、ES / 面接で使う点、Web 由来補足情報を分離する。
- Web 補足は出典、取得日、信頼度、要確認フラグを維持する。
- 志望度や比較用メモはユーザー追記として扱い、紙メモ由来の事実とは混ぜない。

## Phase 全体の検証方針

- ドキュメントのみの Issue では、記述が受け入れ基準を満たすことを確認する。
- UI / ロジックを変更する Issue では、lint、typecheck、test、build を実行する。
- Web 補足や LLM 出力を扱う場合は、紙メモ由来情報との混在がないことをセルフレビューする。

## Out of Scope

- 企業データベースの構築
- ユーザーアカウントやクラウド同期
- Google Drive 保存
- 本番デプロイ設定
